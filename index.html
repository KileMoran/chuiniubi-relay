吹牛逼 备用联机入口

这是为中英两地好友联机准备的 Cloudflare Pages 免费接入测试站。它不会创建新的游戏服务器，所有人仍然连接原来的同一房间。

① 检查游戏服务器可达性

通过 Pages Service Binding 调用原 Worker 的 /health。出现版本号 1.1-voice 表示 HTTP 链路基本可用。

尚未检测。请分别点击两个测试按钮。

② 用备用服务器进入原游戏

本入口将备用 WSS 地址带入原来的 GitHub Pages 游戏页面。英国玩家仍可使用原地址，两端最终连接同一个 Worker。

需要先用同一个昵称加入尚未开局的房间；已开始的房间仅支持此前获得过身份凭证的玩家恢复。游戏内的「高级设置」也可以直接输入本页的 wss:// 地址。

③ 如何判断有没有修好？

先在中国大陆手机上测试本页是否打开，再测试 /health 和 Pages WebSocket。只有两项测试基本通过，才继续尝试进入实际游戏房间。即使牌局联机成功，RealtimeKit 语音仍需单独验证。
